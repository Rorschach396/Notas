# Estandar ASME e ISO 

Existen diferentes tipos de tolerancias que determina la forma, orientación, locación, Runout; Estas pueden ser aplicadas tanto en la parte 3D y 2D. 

- Flatness: Ocupadas en los planos donde se considera que tan plana es la superficie. 
- Straightness: Rectitud de un cilindro. 
- Circularidad: Se revisa las distancias del cilindro en ciertas partes 
- Cilindricidad: Se mide todo el cilindro 
- Angularidad: Se tiene un angulo de referencia, este muestra la distancia que hay en el plano.
- Perpendicularidad: Es  lo mismo, solo que aplicado con 90°.
- Paralelismo: Se tiene de referencia el primer plano solamente y se aplica similar al flatness. 

Posición:
- Posición: Aplicable a ejes
- Perfil de superficies: Aplicado a todo tipo de superficies, donde se puede tener un rango de superficie. 
- Perfil lineal: Lo mismo que el anterior nomás que en una sola lineal 
- Circular runout: Mide la concentricidad respecto a un eje de referencia. 
- Total runout: Lo mismo pero tomando en cuenta la longitud 
- Concentricidad: Se alinean ejes de un determinado cilindro 
- Simetría: hace que sea simétrica dependiendo de un determinado eje 

# Grados de libertad 

Se tiene que considerar las posibles posiciones que pueden tener de una pieza, esto sirve para poder mover o anclar una determinada posición respecto a un eje. 

# MMC y LMC 

MMC = Cuando se tiene más material 
LMC = Cuando se tiene menos material 

Esto genera que casi todo se controle con perfiles.
