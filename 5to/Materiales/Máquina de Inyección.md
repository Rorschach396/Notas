Requiere una gran inversión inicial, esto debido a que las máquinas son muy caras; esto genera que se busque siempre tener una producción ya planeada de determinadas piezas. Polietileno, polipropileno, PET y posiblemente PVC son los polímeros que normalmente se utilizan para poder realizar el proceso de inyección. 

- Máquinas manuales: Materiales que no tienen un alto desempeño 
	- Ventajas: Buena producción
	- Desventajas: Mala calidad
- Máquinas automáticas: Plásticos de ingeniería
	- Ventajas: Se pueden controlar todos los parámetros para el proceso 
	- Desventajas: Muy caro 

# Partes generales de una máquina de inyección 

- Grupo de cierre: sistema de cierre
	- Plato fijo 
	- Plato móvil
- Unidad de inyección: Donde se coloca el material 
- Unidad de control 
- Bancada: Base 

# Ciclo de Inyección

1) Inicio/cierre: La máquina está abierta y la masa se encuentra en el husillo, en este momento se cierra la máquina, este punto debe de ser lo suficientemente rápido para poder aumentar la producción. 
2) Inyección: Cuando se inyecta el polímero fundido al molde.
3) Mantenimiento: Mantener la presión para que las moléculas se puedan mantener acomodadas mientras se enfría el molde. 
4) Plastificación: Tiempo donde se empieza a agarrar más material para poder fundirlo y dejarlo listo para el siguiente.
5) Apertura: Se abre el molde y se tiran las piezas. 
# Variables que se deben de controlar 

1) Fuerza de cierre (kN).
2) Perfil de temperaturas (°C).
3) Velocidad de inyección(mm/s).
4) Presión de inyección(Bar).
5) Presión posterior/presión de mantenimiento (Bar).
6) Revoluciones del husillo (mm/s o rpm).
7) Dosificación ($cm^3$).
8) Cojín de masa ($cm^3$).
9) Presión específica (Bar).
10) Tiempo de enfriamiento (s).

# Ciclo de inyección 

Curvas de proceso

1) Presión de inyección: Presión a la que se inyecta (presión 0-1)
2) Presión de mantenimiento: Se mantiene una presión aunque cambia su volumen y temperatura (presión 1-2)
3) Etapa de refrigeración: Volumen no cambia pero cambia su temperatura (presión 2-3)
4) Enfriamiento fuera del molde: Puede cambiar su temperatura y su volumen (presión 3-4)

Contracción del material: Como es que cambian sus dimensiones cuando se deja enfriar fuera del molde. 

**Amorfos: Poliestireno, policarbonato y polimetilmetacrilato**

# Presión

Existen tres tipos: 

- Presión manométrica: Generada por circuito hidráulico.  
- Presión específica: Presión dentro del molde. 
- Contrapresión: Presión necesaria para controlar el avance del husillo
