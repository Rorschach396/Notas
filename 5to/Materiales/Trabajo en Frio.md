CW% = ((A0 -Af)/A0)x100 

El trabajo en frio es un proceso de deformación plástica que se realiza a temperatura ambiente o ligeramente elevada (por debajo de la temperatura de recristalización del metal). Este al ser un proceso de deformación presenta cambios en la microestructura como los vistos en [[Ensayo de Tracción#**Efectos de la deformación Sobre la Resistencia de los Materiales**]], lo que permite tener diferentes propiedades dependiendo del trabajo que se le haga a una pieza.   

## Procesos de Producción en la Industria

Laminación en frio: Proceso por el cual se pasa a través de dos rodillos un material y se deforma para obtener una lámina más fina; en este proceso el grano se tiende a alargar y para poder recuperar sus propiedades originales se le tiene que dar un tratamiento térmico.

![[Pasted image 20250426234356.png]]

Proceso de Forja: En este proceso se calienta el material (sin llegar a la temperatura de recristalización del material) para poder darle forma a través de la deformación por impacto. 

![[Pasted image 20250426234517.png]]

Proceso de trefilado: Proceso normalmente utilizado para poder producir alambres, en este proceso se utilizan pequeños cabezales similares a un embudo por donde se hace pasar el material para poder educir su diámetro. 


![[Pasted image 20250426234840.png]]

Embutido: Proceso por el cual se realizan piezas como los moldes para repostería, este proceso requiere del uso de una prensa, donde un molde (positivo y un molde negativo) se utiliza para poder obtener la forma deseada. 

![[Pasted image 20250426235035.png]]

Extrusión metálica: Proceso similar a la extrusión de plásticos, solo que al ser con metal se requiere mucha más fuerza para poder obtener el resultado deseado. En el caso de los metales, se utiliza un pistón para poder empujar la pieza de metal a través de un molde o matriz para poder obtener una forma determinada. 

![[Pasted image 20250426235257.png]]

Doblado de láminas: Proceso por el cual se obtienen las láminas de metal, en este proceso se utilizan dos partes de un molde para poder obtener una forma determinada en una lámina de un determinado material. 

![[Pasted image 20250426235511.png]]

## Endurecimiento por Deformación

Cuando a una pieza se le aplica una carga, las dislocaciones se empiezan a desplazar causando una deformación plástica, al momento de generar la deformación, se empiezan a generar más dislocaciones que son más difíciles de mover, por lo que se requiere más energía para poder deformar el material; a este fenómeno se le conoce como endurecimiento por deformación, que se encuentra relacionado con el [[Trabajo en Frio]]

Beneficios 
- Mayor dureza del material 
- Aumento significativo de la resistencia 
- mejor acabado 
- Reducción de las tolerancias 
- Eliminación de defectos superficiales
