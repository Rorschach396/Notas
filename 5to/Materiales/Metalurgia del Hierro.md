
*Metalurgia* = ciencia que estudia todas las propiedades (físicas, químicas, mecánicas) relacionadas con los metales. 

Acero fundido = acero con más de 2% de carbono, el cual está segregado. 

El hierro presente en la fundición es duro y frágil, normalmente se tienden a utilizar en piezas que no estén sometidas a esfuerzos o a cambios rápidos de temperatura.

Si al acero se le elimina por completo el carbono pierde casi todas sus propiedades mecánicas, pero si se elimina solo una parte del carbono y le agregamos algunos metales, se pueden obtener una mezcla más tenaz conocida como acero; los principales metales que se le agregan son Mn, Cr, Ni, W, Mo y V. 

Aceros inoxidables: Aceros que contienen 14-18% de Cr y 7-9% de Ni, los aceros inoxidables si se oxidan pero gracias al cromo se sacrifica para poder producir una capa de óxido que evita que se siga oxidando el metal. 

Dependiendo del radio iónico que tengan los metales, se puede saber si son átomos intersticiales o sustitucional, esto permite tener diferentes propiedades:

Para poder pasar el hierro a acero se tiene que tener los siguientes cambios fundamentales: 
- Reducir (en términos químicos) el contenido de carbono de 3-4% a 0-1.5%
- Eliminar mediante formación de escorias el Si, Mn y P con otras impurezas
- Añadir elementos de aleación como el Cr, Ni, Mn, V, Mo, y W para poder obtener las propiedades deseadas. 

Para obtener acero se utilizan hornos de oxígeno básico, esto para poder eliminar el carbono presente en el material a través de la formación de $CO$ y $CO_2$. También se añade piedra caliza o sílice en polvo sobre el hierro para poder formar escorias, las cuales permiten eliminar elementos no deseados como el Si, Mn y P. Cuando ya se formó la escoria, el recipiente de reacción se inclina o bascula para poder retirar esta parte que no es útil.

Luego se precipita $Al_{2}O_{3}\cdot xH_{2}O$ para luego deshidratarlo
