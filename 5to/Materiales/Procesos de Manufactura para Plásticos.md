
Extrusión, inyección y termoformado = procesos para termoplásticos solamente. 

Hay 3 tipos de plásticos: Comodities, ingenieríles y especiales; cada uno aumenta su nivel de propiedades mecánicas relativas.

Las piezas que se obtienen pueden ser clasificadas como piezas individuales  o semielaboradas, 

- individuales 
	- moldeo 
	- combinación de varios procesos 
	- procedimientos de acabado 
- Semielaborados 
	- extrusión 
	- colada
Procedimientos de acabado: Procedimientos que se le hacen al plásticos para poder eliminar o agregar esfuerzos superficiales, también se puede hacer soldadura de plástico, pegado, mecanizado, ajuste a presión y marcaje. 

Casi todos los plásticos son utilizados en el empaquetado, donde surge el problema de los desperdicios. En México el 72% del plástico es usado en embalaje, lo demás se distribuye en todas las demás industrias. 

Extrusión de película: Se hace una burbuja que se va jalando, normalmente utilizado para hacer bolsas. 

Soplado: Cuando se toma un tubo se funde sin que se empiece a caer, se le inyecta aire y toma la forma. 

Solapado de preforma: Similar al anterior, solo que primero se hace una preforma que luego se calienta y se sopla. 

Roto moldeo: Se utiliza polvo de plástico, donde se aplica calor y se rota tanto en el eje x y el eje y, produciendo una pieza hueca. 

Inyección de plásticos: La más conocida, se utiliza para casi todo.
