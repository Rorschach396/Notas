# Practica de CENISA

En el caso de esta practica no se menciona como se tiene que realizar el decapado de las piezas a cobrizar; en un cierto momento se menciona una solución ácida (ya sea de HCL o $H_{2}SO_{4}$) pero no se especifica para que va a ser utilizada. También se menciona que **se debe de utilizar una solución saturada de sulfato de cobre**. 

# Propuestas de cambio 

En el caso de la practica se propone que se haga el cambio en la solución debido a que con las fuentes consultadas se pudo ver que a la solución para realizar el cobrizado se utiliza una mezcla ácida junto con al sulfato de cobre. Los ratios que se lograron encontrar descritos son los siguientes: 

| Componente        | Concentración |
| ----------------- | ------------- |
| Sulfato de cobre  | 0.375 g/L     |
| Ácido Clorhídrico | 37% (v/v)     |

Otro posible cambio que se puede realizar para poder aplicar el cobrizado es realizar la electrodeposición en un electrodo previamente capado con zinc, esto podría ser hecho por el laboratorista (o en este caso nosotros) antes de realizar las pruebas, esto debido a que se vio que en bastantes fuentes se recomendaba que se realizara este procedimiento previo para poder mejorar la eficiencia del mismo.
