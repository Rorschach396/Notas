
Como ya se vio en [[Ensayo de Dureza]], se pueden determinar la dureza de las piezas con el uso de ciertas pruebas, pero para poder obtener datos reales en cada una de las pruebas (mayormente en las pruebas de microdureza) es necesario que se prepare la superficie de la muestra de la siguiente forma: 

1) Corte de las muestras o probetas: En este paso se obtienen las muestras a probar con las diferentes pruebas de dureza o incluso para [[Ensayo de Tracción]]; en este momento se tiene que tener mucho cuidado a la hora de cortar la pieza debido a que se tiene que asegurar que no se genere un calor excesivo que pueda interferir con la microestructura y pueda generar que se pierdan o se obtengan nuevas propiedades. Idealmente la superficie de la muestra debe de quedar libre de daños térmicos y sin deformación o distorsión mecánica (idealmente).
2) Lijado y pulido: El lijado de las piezas se realiza para poder obtener una superficie homogénea para poder realizar las pruebas, para esta parte se utilizan las lijas de carburo de silicio, las cuales tienen un tamaño de grano que determina cuantos granos hay por unida de área (entre más alto el número, más fina es la lija) las que más se suelen utilizar son: 180, 220, 360, 400, 500, 600, 800, 1000 y 1200; para poder realizar el lijado se tiene que ir rotando 90° entre cada lija y aparte se tiene que que hacer en sentido perpendicular a las líneas que dejara el método de corte. A la hora de realizar el pulido es necesario colocar un paño donde se coloca un abrasivo (como la alúmina o pasta de diamante) aparte de agregar una gran cantidad de agua que funciona como lubricante.
