Hay células que tienen que estar adheridas para poder sobrevivir, esto también sucede con las bacterias. 

Para que las partículas se puedan tocar es necesario que superen las barreras que se generan debido a las cargas superficiales. Cuando ya están muy cerca las partículas es prácticamente imposible poder separarlas. Depletion, es un tipo de fuerza de interacción, se puede interpretar como un agotamiento, es un gradiente. 

el DLVO es un límite que se tiene que superar para poder juntar a las partículas, es como una colina que, cuando se supera, estas se juntan completamente. 

Cuando una partícula toca una célula se encuentra con la membrana celular.
