#  Redes 
Existen 3 tipos de redes: 
- Unidimensionales 
- Bidimensionales 
- Tridimensional 
Estas se describen por medio de vectores 

Hay varios tipos de redes bidimensionales, entre estas destacan: 

- Oblicua 
- Rectangular 
- Rectangular centrada 
- Cuadrada 
- Hexagonal

Existen 7 sistemas cristalinos: 
- Cúbico o isométrico 
- Tetragonal 
- Hexagonal 
- Trigonal 
- Ortorrómbico 
- Monoclínico 
- Triclínico
