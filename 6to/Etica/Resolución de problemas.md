- Poder: Capacidad de afectar la conducta de alguien
	- Coercitivo: Basado en la fuerza
	- Utilitario: Cuestiones materiales o financiero 
	- Narrativos: Simbólico/normas 
- Legitimidad: creencia de un bien
	- legitimidad + poder = autoridad 
- Urgencia: 
	- Temporal: Tiempo que se tiene para resolver el problema 
	- Relacional: Se tiene una conexión con el grupo de interés
