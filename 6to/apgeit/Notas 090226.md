Acta de proyecto 
- Idea principal del proyecto %%El conocimiento empírico puede funcionar, pero no es lo mejor%%
- Antes de realizar cualquier proceso es necesario identificar al cliente para poder venderle el producto, todo se inicia con el marketing 
	- jobs to be done: Cosas que se necesitan, análisis de las mismas 
	- Frustraciones: Cosa que perjudican al cliente o que no lo dejan completamente satisfecho 
	- Beneficios: Cosas que reciben los compradores del producto 
	- A los 3 puntos anteriores se les conocen como canvas de valor o propuesta de valor para el cliente 
- Para hacer un proyecto se requieren mínimo 100 entrevistas (técnica de los 5 porque) . 
- A partir de las frustraciones se pueden realizar cambios para poder vender más 
- Los beneficios se pueden incrementar o mantener, nunca eliminar.
- Las frustraciones y los beneficios son más fácil de encontrarlos a través de entrevistas o de observación
- Linkedin normalmente funciona para poder identificar a posibles compradores de mi industria y así las posibles necesidades
- Todos tienen necesidades, todos tienen frustraciones y todos 
- Se debe de analizar a la persona para poder saber como venderle
