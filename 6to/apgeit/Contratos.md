Tipos de contrato: 

- Contrato de precio fijo: Todo el precio cae sobre el proveedor, proyectos cortos, proyectos ya bien establecidos, presupuesto blindado
- Tiempo y materiales: Se paga por las horas en las que se ocupa la maquinaria, 
- Costos reembolsables: Si algo sale mal no hay pedo 

El precio fijo tiene un mayor precio para poder hacer que el proveedor gane más, se pueden combinar los contratos para poder obtener un mejor precio. 

Los posibles aumentos de precios se pueden dar como una seguridad en caso de algún imprevisto. Normalmente el precio fijo es para cosas pequeñas, nunca para cosas más grandes. 

Normalmente se les pide el 50% de anticipo, también es recomendable tener un seguro de responsabilidad civil, este seguro respalda cualquier contingencia si se llega a tener un problema con tu mercancía.

La NOM 151 se tiene que cerrar primero el proyecto para después firmar los contratos. 

KPI: Para poder saber si se están alcanzando las metas

Reserva de contingencia es para riesgos conocidos

Existe una reserva para los riesgos desconocidos (reserva de gestión)

WBS: debe de tener todo lo del proyecto, debe de tener solo entregables (resultados tangibles), se empieza del proyecto completo y se descompone en pequeñas tareas individuales. Se tiene que enfocar en que se tiene que entregar, no se tiene que dejar nada fuera y se tiene que tener una cantidad de trabajos específica, no muy agobiante. 

TCO (total cost of ownership): Costo construir mas lo que cuesta mantenerlo 
CAPEX: Costo en hacer la empresa 
OPEX: Costo  para mantener abierto 
ROI: Retorno 

Algoritmos de estimación de costos: Comparar un módulo de proyectos similar anterior. Paramétrica: Regla de tres 
Técnica de tres puntos: Costo = (optimista + (4xmás probable)+pesimista)/6

Reserva de contingencia es de 10% - 15% la reserva de gestión es de un 5%
