- Switch selector de posiciones: Similar a la perilla de una estufa, puede dar un máximo de 3 posiciones (hasta ahora) y ya cuenta con una pieza plástica para el manejo. 
- Pulsadores: Se requiere una mayor cantidad y una pieza para poder pulsarlo, puede permitir tener una mayor cantidad de velocidades.
