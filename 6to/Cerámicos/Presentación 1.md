Existen 3 técnicas principales para el moldeo de la arcilla
- Modelado: Consiste en formar la pieza solo con las manos uniendo ciertas formas para poder dar forma a la pieza final, se pueden utilizar rollos de arcilla o porciones geométricas de arcilla. 
- Moldes
	- Moldes de prensado: Donde se coloca la arcilla a la que se le quiere dar forma y se presiona para poder darle una determinada forma. 
	- Moldes de colado: En estos se vierte la arcilla líquida para poder darle forma después 
- Torneado: Utiliza la fuerza centrífuga para poder darle forma a los objetos, este fue originalmente utilizado y girado con la mano, lo que permitía hacer piezas pero no era muy bueno; el torno se perfeccionó con el torno de pie, el cual permitía tener una rotación continua para poder obtener mejores resultados. 

Después de que la arcilla ya tenga forma se procede a hacer el secado para poder eliminar humedad, este se debe de realizar en una zona que no tenga una gran cantidad de calor o se puede realizar una precocción a bajas temperaturas. 

Después de secarla se retocan las piezas utilizando espátulas o cuchillas, en este paso se perfecciona la superficie de la pieza con el fin  de reducir la porosidad y mejorar su aspecto. 

La decoración inicialmente solo se hacía utilizando las propiedades mecánicas del mismo barro, en este caso se le podía perforar o realizar impresiones. Luego se empezó a utilizar arcilla sobre la pieza seca para poder realizar detalles, la arcilla nueva que se colocaba se encontraba pintada. El siguiente paso que se dio a la hora de decorar ciertas piezas fue el vidriado, en esta técnica se utiliza plomo o estaño mezclado con arena y sílice.
